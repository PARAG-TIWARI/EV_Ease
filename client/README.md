# EVEase frontend

This directory contains the React + Vite interface for the EVEase prototype.

## Local development

~~~bash
npm ci
~~~

Create a local environment file named .env.local:

~~~env
VITE_API_BASE_URL=http://localhost:8000
~~~

Start the Vite development server:

~~~bash
npm run dev
~~~

Open http://localhost:5173.

The AI Planner sends requests to the FastAPI service using VITE_API_BASE_URL. Vite exposes its environment values in the browser bundle; do not put Google Maps or OpenRouter API keys in this file.

## Quality checks

~~~bash
npm run lint
npm run build
~~~

## Hosting

Firebase Hosting configuration is in firebase.json in this directory. The hosting public directory is dist, which is generated by npm run build.

For the Firebase project and deployment workflow, see the repository root README and the workflows in .github/workflows.
